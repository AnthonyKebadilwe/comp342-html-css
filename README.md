## How to practice
1. Install [VS Code](https://code.visualstudio.com/) and the **Live Server** extension (VS Code will suggest it).
2. Open this folder in VS Code (*File > Open Folder*).
3. Read a lesson's `README.md`, then open its `examples/` and run them with *Right-click > Open with Live Server*.
4. Go to `practice/`, complete every `TODO`, and save – the browser refreshes automatically.
5. Do the extra exercises, then write your notes at the bottom of the lesson README.
